# 체스 분석

Stockfish 19 기반 한국어 체스 분석과 친구 간 실시간 1대1 대국을 지원합니다. 닉네임/비밀번호 가입, ChatGPT 계정 연동, 친구 목록과 초대 링크, 경기 기록, 10가지 기물 디자인을 제공합니다.

## 저장소 구성

- 루트의 `src/`, `online/`, HTML/CSS: 분석 화면, 대국 화면, 인증과 대국 로직의 원본
- `tests/`: 체스 규칙, 인증, 대국, 분석 관련 자동 테스트
- `sites/chess-analysis/`: Cloudflare D1과 Vinext Worker를 사용하는 Sites 배포 프로젝트
- `scripts/package-static.mjs`: 원본과 설치된 의존성으로 배포 파일 생성

저장소에는 비밀번호, 세션, 실제 사용자 DB, 로컬 기보, 로그를 포함하지 않습니다. Stockfish WASM과 chess.js 배포 파일은 의존성 설치 후 생성합니다.

전체 프로젝트에는 Node.js 22.13 이상이 필요합니다. 분석 화면만 로컬 실행할 때는 아래 실행 절차를 따르세요. 배포 프로젝트를 준비하려면 루트에서 다음 명령을 실행합니다.

```sh
npm install --ignore-scripts
node scripts/package-static.mjs
cd sites/chess-analysis
cp .openai/hosting.example.json .openai/hosting.json
npm ci
npm run dev
```

최초 설치 시 설정 예시를 복사하고 본인의 프로젝트 ID를 입력하세요. 기존 로컬 설정이 있다면 덮어쓰지 마세요. 실제 사이트 설정은 Git에서 제외됩니다. ChatGPT 로그인 연동은 Sites 호스팅의 인증 기능을 사용합니다.

## 실행

Windows에서 `start.cmd`를 더블클릭합니다. 브라우저 주소는 **http://127.0.0.1:4173** 입니다. 실행 창을 닫으면 서버가 종료됩니다.

소스를 처음 받은 컴퓨터에서는 Node.js를 설치한 후 다음 명령을 실행합니다.

```sh
npm install --ignore-scripts
npm start
```

`start.cmd`는 PATH의 Node.js를 사용하고, 이 컴퓨터에서는 Codex에 포함된 Node.js도 자동으로 찾습니다. 기본 포트를 다른 프로그램이 사용한다면 PowerShell에서 `$env:PORT=4174; node server.mjs --open`으로 실행할 수 있습니다.

## 기능

- PGN 붙여넣기/파일 열기, FEN 단일 국면 불러오기
- 합법적인 수 검증, 기보 탐색, 보드 뒤집기
- 국면별 엔진 평가, 기물·출발/도착 칸·상대 응수로 표시하는 최대 3개 추천 수와 수순 재생
- 전체 대국 분석, 진행률, 중단 및 이어서 분석, 부분 분석 상태에서 ‘처음부터 분석’으로 전체 재분석
- 같은 기보의 탭 전환·자유 탐색·전구·배치 편집 중에도 전체 분석을 계속하며 현재 보드와 탐색 수순을 유지합니다. 원본 기보·자유 탐색·전구가 설정한 작업 한도를 함께 사용하고, 다음으로 비는 슬롯은 자유 탐색·전구에 우선 배정합니다. 1개 작업에서는 현재 국면의 깊이 계산이 끝난 뒤 탐색을 먼저 처리하고 원본 분석을 이어갑니다. 명시적 중단·새 기보 불러오기·페이지 종료는 전체 작업을 중단하며, 분석 조건 변경 시에는 새 조건으로 전체 분석을 다시 시작합니다.
- 자유 탐색·전구 계산이 대기 또는 실행 중이면 원본 기보의 새 작업은 최대 1개로 줄입니다. 진행 중인 원본 계산은 깊이를 채우며, 탐색이 끝나면 짧은 350ms 유예 후 전체 작업 수로 복귀합니다. 1개 작업 설정에서는 탐색 동안 원본의 새 작업을 대기시킵니다. 캐시나 재생만 보는 동안에는 원본 작업 수를 줄이지 않습니다.
- 평가 그래프와 수별 분류, 주요 실수 목록. 자유 탐색에서는 분기 지점까지의 원본 평가 뒤에 탐색 평가를 이어 그리고, 기보·분석 요약 탭에서는 선택한 원본 국면의 보드와 전체 그래프를 표시합니다. 자유 탐색으로 돌아오면 이전 탐색 위치·수순·해설을 복원합니다.
- 기물을 클릭하거나 추천 수를 선택해 분기 탐색, 승격 기물 선택
- 원본 대국으로 복귀, 현재 FEN 복사, 평가 주석을 포함한 PGN 저장
- 마지막 대국·선택 국면·분석 결과를 브라우저에 자동 저장
- 화면 하단에 항상 표시되는 평가 그래프: 원본 대국/탐색 수순 전환, 클릭·방향키로 이동
- 자유 탐색 그래프는 탐색 시작점까지의 원본 평가와 새 탐색 평가를 연결합니다. 원본의 이후 수 평가를 탐색 결과로 사용하지 않으며 미분석 구간은 비워 둡니다.
- 자유 탐색의 판정에는 부모와 자식 모두 같은 국면 분석 설정의 결과를 사용합니다. 원본 리뷰가 먼저 끝났더라도 후보 수나 깊이가 다른 원본 캐시를 그대로 판정 근거로 사용하지 않습니다.
- 기보를 불러오면 미분석 국면을 자동으로 분석하며 빈 구간은 미분석으로 표시
- 추천 수순 자동 재생, 일시정지, 속도 조절, 수별 이동·잡기·체크 설명과 기물 애니메이션
- 자유 탐색에서 이전·다음 이동, 기존 수순 중간에서 다른 수를 두면 이후 분기 교체
- 배치 편집에서 기물 이동·추가·삭제와 차례 선택, 유효성 검사 후 분석
- 선택한 기물의 합법적인 이동 칸 표시
- 내 기보: 최대 50개 대국과 분석 결과 저장·불러오기, 삭제 취소
- 색상·평가 손실 기준 기보 필터, 이전·다음 실수 이동
- 원본과 탐색 수순 각각 PGN 미리보기·저장·복사, 기물 점수 비교
- 상단바의 대국 정보·분석 깊이·전체 대국 분석·배치 편집, 왼쪽 체스보드와 오른쪽 통합 패널(엔진·기보·자유 탐색·분석 요약)
- 체크 시 원래 칸 색을 유지하는 붉은 표시와 현재 차례의 플레이어에 빛 효과 표시
- 통합 패널 내부에서 수 목록을 스크롤하며 탭을 전환해도 탐색 수순 유지
- 추천 기물을 선택하면 합법수 표시와 추천 화살표를 함께 유지

좌우 방향키로 수를 이동하고, Home/End로 처음/마지막으로 이동합니다. F는 보드 뒤집기입니다. 수순 탐색 중에는 방향키가 탐색 수순을 따라 이동합니다. Space는 수순 재생/일시정지입니다(입력 칸과 버튼에 포커스가 있을 때는 해당 컨트롤의 동작을 우선합니다).

원본 PGN 저장과 탐색 PGN 저장은 별개입니다. 탐색 PGN에는 시작 위치까지의 수순과 전체 탐색 수순, 이동 설명, 분석된 평가가 포함되며 가상 결과이므로 Result는 `*`입니다. 배치 편집으로 만든 국면은 FEN을 함께 저장합니다. 이름을 붙인 기보에는 원본 대국과 저장 버튼을 누를 때까지의 분석이 저장됩니다. 같은 기보를 다시 저장하면 최신 결과로 갱신됩니다. 브라우저 저장 데이터를 지우면 내 기보도 사라지므로 필요한 기보는 PGN 파일로 내보내세요.

자유 탐색은 일반 체스 규칙과 차례를 따릅니다. 임의 배치를 원하면 배치 편집을 사용하세요. 배치 편집은 원본을 바꾸지 않으며 적용 시 캐슬링/앙파상 권리와 반수 시계를 초기화합니다. 왕의 존재, 왕의 안전, 폰 위치 등을 검증한 뒤 엔진에 전달합니다.

추천 수순은 엔진이 제시한 한 가지 응수 예시이며 상대의 실제 선택을 보장하지 않습니다. 수별 설명은 이동 방향, 잡힌 기물, 캐슬링, 앙파상, 승격, 체크/메이트 등 보드에서 확인할 수 있는 사실을 사용합니다. 재료 점수는 폰 1, 나이트/비숍 3, 룩 5, 퀸 9로 합산하며 엔진 평가와 다릅니다.

## 평가 기준

평가는 항상 백 기준입니다. 양수는 백 우세, 음수는 흑 우세입니다. `+M3`는 백이 최선의 수를 두면 3수 안에 메이트할 수 있다는 엔진 평가입니다. 기보의 실제 경기 결과와 현재 국면의 엔진 평가는 별개입니다.

상단 엔진 이름을 누르면 엔진 및 성능 설정을 엽니다. Stockfish 19 Lite(약 2MB)와 Stockfish 19(약 95MB)를 선택할 수 있습니다. 큰 엔진 파일은 선택했을 때만 내려받습니다.

깊이는 12/16/20/24, 라인 수는 1/2/3/5개, 작업당 해시 메모리는 16/32/64/128/256MB로 설정합니다. 판정에 쓰는 검색은 시간 제한으로 조기 종료하지 않고 설정한 깊이를 완료합니다. 전구 심층 확인 시간은 별도 설정이며 기본 리뷰 판정을 바꾸지 않습니다. 설정은 기보와 함께 브라우저에 저장됩니다. 작업 수나 전구 시간만 바꾸면 완료된 평가와 보고 있던 해설 수순을 유지합니다.

전체 대국은 단일 스레드 엔진 여러 개가 서로 다른 국면을 나눠 분석합니다. 자동은 감지한 논리 스레드의 약 40%, 수동은 50% 이하에서 최대 8개 작업을 지원합니다. 단일 논리 스레드 기기에서는 최소 1개 작업을 사용합니다. 이 비율은 실제 CPU 사용률 제한을 의미하지 않습니다. 각 검색 전에 엔진의 해시와 검색 이력을 초기화하므로 작업 수가 탐색 조건에 영향을 주지 않습니다. 이 방식은 공유 메모리나 브라우저 격리가 필요하지 않습니다. Lite는 작은 신경망을 사용하는 경량 엔진입니다.

수 분류는 탁월수, 훌륭한 수, 최선의 수, 우수한 수, 좋은 수, 이론, 부정확, 실수, 놓친 기회, 블런더의 10개입니다. Chess.com의 공개 예상 승점 감소 경계(2/5/10/20%p)를 참고하되, 자체 환산식 `1/(1+exp(-cp/250))`를 사용합니다. 레이팅별 비공개 모델이나 정확도 점수는 재현하지 않습니다. 상대에게 새 강제 메이트를 허용하면 블런더, 자신의 강제 메이트를 놓치면 놓친 기회로 분류합니다. 같은 쪽의 강제 메이트가 유지되면 거리 차이는 손실로 계산하지 않습니다. 수 목록 필터와 실수 탐색도 동일한 분류를 사용합니다.

탁월수는 유리하거나 균형에 가까운 국면을 유지하며 실제 예상 응수에서 희생이 확인될 때, 훌륭한 수는 두 번째 후보와 예상 승점 차이가 10%p 이상인 최선의 수일 때 보수적으로 추정합니다. 상대 실수로 새로 생긴 우세를 살리지 못한 경우도 놓친 기회로 구분합니다. 이론 수는 `lichess-org/chess-openings` CC0 자료의 첫 20번 이동(10수)까지 등록된 수순과 대조하며, 자료가 모든 오프닝을 포함하지는 않습니다. 원본 자료와 해시는 `data/openings/`, 생성기는 `scripts/build-opening-book.mjs`입니다.

전체 대국은 기본적으로 정밀 검토를 사용하며 후보 수는 최대 2개입니다. 빠른 검토는 선택한 깊이보다 2단계 낮은 깊이(최소 8)를 완료합니다. 두 모드는 탐색 깊이가 다르므로 평가와 분류가 달라질 수 있습니다. 희생·후보 순위·메이트 확인에도 같은 깊이 완료 정책을 적용하며, 불완전한 결과를 완료된 판정으로 저장하지 않습니다. 워커는 재사용하고 검색은 순서대로 실행하며, 취소된 검색의 `bestmove`를 받은 뒤 다음 검색을 시작합니다. 캐시 버전 `review-v8`은 이전 시간 제한 결과를 제외하고 작업 수 변경 시 같은 분석을 재사용합니다.

일반 체스와 단일 대국 PGN만 지원합니다. Chess960 같은 변형 체스는 지원하지 않습니다. FEN만으로는 그 이전의 반복 이력을 알 수 없습니다. PGN에서는 수순을 엔진에 함께 전달하여 반복 이력을 유지합니다. 3회 반복 및 50수 규칙은 무승부 청구 가능 상태로 표시합니다.

## 데이터와 구조

기보 분석은 브라우저에서 처리됩니다. 온라인 대국의 계정, 친구 목록, 경기 기록은 서버의 D1 데이터베이스에 저장됩니다. 로컬 분석 서버는 `127.0.0.1`에만 바인딩하며 지정된 앱 파일만 제공합니다.

- `server.mjs`: 의존성 없는 Node.js 정적 서버
- `src/app.js`: 화면, 분석 작업, 취소, 브라우저 저장
- `src/chess-core.js`: 기보, 합법수, UCI 파싱, 평가 및 내보내기
- `src/engine.js`: Stockfish Web Worker 통신
- `src/engine-options.js`: 엔진 선택, 성능 설정, 대형 엔진의 분할 다운로드
- `src/pieces.js`: SVG 체스 기물
- `src/sample.js`: 제공한 대국
- `src/study.js`: 탐색 수순과 기록 보존, 수별 설명, 배치 편집 검증, 기물 가이드, 탐색 PGN

node --test tests/*.test.mjs

## 온라인 1대1 대국

배포 사이트의 `/play`에서 이용합니다. 닉네임과 8자 이상의 비밀번호로 가입하거나 ChatGPT로 로그인할 수 있으며, 두 로그인 방식을 한 계정에 연동할 수 있습니다. 닉네임과 친구 코드만 상대에게 표시합니다. 친구 목록에서 보내는 대국 요청과 초대 링크 참가를 모두 지원합니다.

- 시간: 10분, 10+5, 15+10, 20분, 30분, 60분. 각자의 시간이며 `+5`, `+10`은 합법적인 수를 확정할 때마다 더하는 초입니다. 상대가 참가하면 백의 시계가 시작합니다.
- 즉시 두기 / 놓기 전 확인. 드래그앤드롭과 기물·도착 칸 클릭을 지원합니다. 확인 모드의 미리보기는 서버에 전송되지 않습니다.
- 기권, 무승부 요청과 상대의 수락/거절, 한 수 무르기 요청. 무르기는 마지막 반수 1번만 취소하며, 받은 추가 시간은 회수하고 이미 사용한 시간은 돌려주지 않습니다. 다음 수가 진행되면 기존 요청은 만료됩니다.
- 서버가 합법 수, 차례, 대국 참가 권한, 버전 충돌, 남은 시간과 종료 결과를 검증합니다. 클라이언트는 약 1.5초 간격으로 최신 상태를 받고, 끊겼다 돌아와도 서버의 시계를 이어받습니다.
- 체크메이트, 스테일메이트, 기물 부족, 3회 반복, 50수 규칙, 기권, 시간 초과, 무승부 합의를 저장합니다. 시간 초과 시 상대가 왕만 남아 있으면 무승부입니다.
- D1에 대국과 경기 기록을 저장합니다. 경기 기록은 페이지를 넘겨 조회하며 참가자만 PGN을 열 수 있습니다. 완료된 경기에서 분석하기를 누르면 기존 Stockfish 분석 화면으로 연결됩니다. 대국 중에는 분석 링크를 제공하지 않습니다.

호스팅 소스는 `sites/chess-analysis`의 Vinext Worker로 전환되었으며 `DB` D1 바인딩과 `drizzle/` 스키마 마이그레이션을 사용합니다. `node scripts/package-static.mjs`가 기존 분석 파일과 대국 클라이언트를 `public/`에, 서버 모듈을 `online/`에 동기화합니다. Sites 빌드/배포 도구로 배포합니다. 로컬 대국 미리보기는 이 체크아웃에서 `npm run dev`로 실행하는 5173 포트를 사용합니다. 기존 4173 분석 서버가 이를 프록시하며, 5173이 없으면 실행 안내를 표시합니다. 선택적으로 `PLAY_SITE_URL` 환경 변수에 대체 대국 페이지 주소를 지정할 수 있습니다. 서버 인증 검증 스크립트는 `CHESS_TEST_ORIGIN` 환경 변수로 지정한 서버에만 요청합니다. 로컬 테스트 로그인은 `127.0.0.1`과 `localhost`를 서로 다른 테스트 참가자로 구분합니다. 이 모의 로그인 코드는 배포 빌드에 포함되지 않습니다.

기물 점수 옆의 잡은 기물은 실제 기보 이력으로 계산하며 앙파상과 승격, 무르기를 반영합니다. 분석 보드와 대국 보드의 임시 표기는 오른쪽 드래그로 화살표, 오른쪽 클릭으로 칸 강조를 토글합니다. 모바일에서는 표기 모드를 켜고 드래그/탭합니다. 표기는 본인 화면에만 남고 수를 두거나 국면을 바꾸면 지워집니다.

친구 코드는 계정마다 고정됩니다. 친구 추가로 내 목록에 저장한 후, 시간과 색을 선택하고 이름 옆의 대국 신청 버튼을 누릅니다. 친구 목록은 계정별로 저장되며 친구의 닉네임 변경을 반영합니다. 목록에서 제거해도 경기 기록은 유지됩니다.
